# How to Run

# Using Eclipse

1. Open Eclipse IDE.
2. Import or open the `JavaProject`.
3. Open the required `.java` file.
4. Right-click the file.
5. Select Run As → Java Application.
6. View the output in the Console.

# Using VS Code

1. Open `JavaProject` in VS Code.
2. Open the required `.java` file.
3. Make sure Java is installed.
4. Click Run.
5. View the output in the Terminal.
